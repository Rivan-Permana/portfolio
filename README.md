# Rivan Permana · Portfolio

Personal portfolio built with Next.js 15 (App Router, static export), TypeScript and a small hand-written design system.

- **Type:** Newsreader (story), Geist (interface), Geist Mono (metadata)
- **Motion:** scroll-settle reveals, an interactive voice waveform, chapter progress rail; all disabled under `prefers-reduced-motion`
- **Content:** every word lives in `content/site.ts`

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export in ./out
```

Deployed on Vercel.
